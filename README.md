## 陪伴是最好的教育 ——— 致每位家长

<br />

心理学认为，陪伴是最好的教育。<br />
陪伴最大的作用，就是让孩子感受到爱，树立起自信心。<br />
父母和孩子的互动，是影响孩子目前行为的一个关键因素。

高质量的陪伴是要真正进入孩子的内心，和孩子一起分享他或她的快乐、<br />
收获、悲伤，理解和接纳孩子的一切，孩子就会形成良好的安全感和自尊心；<br />
反之，低质量的陪伴会让孩子感到自卑、多疑，难以建立自信，<br />
在学校难以和老师、同学建立良好的关系，在家难以和父母建立亲密关系。<br />

有的家长认为，陪伴就是与孩子在一起，就是时空同在，共同生活，<br />
只注重学习上的陪伴，陪写作业，陪上课外班，这是对陪伴理解的窄化。<br />

陪伴应涉及孩子生活的方方面面，<br />
父母陪孩子读书，就会让孩子感受到阅读的快乐；<br />
父母陪孩子吃饭，就会让孩子感受到家庭的温暖。<br />
高质量的陪伴是保持“灵魂的在场”，丰富、温暖且充满活力的家庭生活，<br />
是孩子成长教育的沃土，滋养孩子的品格与心灵！

家庭是孩子的第一所学校，父母是孩子的第一本教科书，高质量的陪伴是最好的教育!
